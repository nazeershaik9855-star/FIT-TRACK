Core Features
1. Dual-Module System
User Module:
Log workouts and daily physical activities.
Track daily steps, heart rate, and sleep patterns.
Record meals and monitor calorie intake.
Set fitness goals such as daily steps or weekly workouts.
View fitness progress and activity reports.
Receive personalised health tips and recommendations.
Admin Module:
Manage registered users.
View, search, and remove users.
Manage workout types and calorie information.
Maintain food items and calorie data.
Monitor overall activity and goal completion.
Publish health tips and recommendations for users.
View dashboard statistics such as total users, workouts logged, and active goals.
2. Authentication & Data Management
User Authentication: Signup and login functionality using browser localStorage.
Role-Based Access: JavaScript identifies whether the logged-in account is an Admin or User and redirects them to the appropriate module.
Local Data Storage: User accounts, workouts, meals, goals, tips, and session information are stored using browser localStorage.
User Data Management: Fitness records are maintained within the browser for this SDC project.
Health Data: Heart-rate and sleep information are simulated using JavaScript as part of the current implementation.
3. Responsive Layout
Built using modern CSS Flexbox for navigation bars, sidebars, and button layouts.
Uses CSS Grid for dashboard cards, forms, reports, and content sections.
Responsive design allows the interface to adapt to laptop and mobile screens.
Provides a simple and user-friendly fitness dashboard for tracking daily progress.
Technology Stack
Frontend: Pure HTML5, CSS3, Vanilla JavaScript
Layout: CSS Grid & CSS Flexbox
Application Logic: JavaScript
Authentication: JavaScript + Browser localStorage
Storage Engine: Browser localStorage (JSON data)
Data Management: LocalStorage-based fitness records
Version Control: GitHub
Deployment: GitHub Pages
Backend: No backend; developed using only HTML, CSS and JavaScript
